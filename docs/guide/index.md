# Guide

Every page is a markdown file under `docs/`. The folder structure becomes the
URL structure, and `index.md` becomes the directory index.

## The short version

1. Write markdown in `docs/`.
2. Put site settings in `docs.json`.
3. Put navigation in `sidebar.json`.
4. Run `docs-go build` or `docs-go dev`.
